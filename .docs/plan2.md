# 1 お客さんが自動で来店する仕組み
 * お客さんは一定時間のスポーン感覚で生成される。
  * スポーン間隔で生まれて、もし満席の場合は店の外に並ぶ。
* 1日の時間が終わって営業終了時、並んでいたお客さんや店の中のお客さんはすぐ帰宅する。（食事中の場合は、直ちに食事完了してお金を払う。
* そして、全スタッフも定位置に戻って処理を停止する。
* フッターのお客さん追加ボタンは廃止する

# 2 1日の営業終了を、自動ではなくユーザーがボタン押下した瞬間にする
* 時間ゲージがいっぱいになり、#1の使用でお客さんが最後の代金を支払っても、金額が達成しなかった場合、ゲームオーバーウィンドウを即座に出す
* 一方、満たしている場合は、「閉店」ボタンを押すことで、営業終了ダイアログを表示する。
* またさらに、ノルマ表示をわかりやすくするために、ヘッダー側にノルマ表示する。「サイゼリアシミュレーター」の文字は無くして、左側に時間制限の丸ゲージ、その右にノルマゲージを出して、現在金額と一緒にノルマの数値も出す。
* 閉店ボタンは、制限時間ゲージの真ん中に「次の日へ」的な表示を出せばOK。

# 3 メニュー追加タイミングの刷新
* ゲームループとして、今後はメニューの追加や店員の購入などを、いつでもショップウィンドウから可能にします。
 * そのために、まずはゲームループを少し変えます。
 * まずゲーム開始時は1日目の営業開始直前ステートである。
 * フッター側に「ショップ」ボタンを作成
 * ショップボタンを押してショップウィンドウを開ける
 * ショップウィンドウは、5つ商品が抽選で並んでいる。まだメニューだけでいい。（メニューは種類csvに足りなければ適当に2つ追加して。
 * ラインナップは「、営業終了して「次の日」になった瞬間に更新される。
 * ラインナップはお金を払ってリロール更新できる。お金を払うごとに要求金額が指数関数（＾２）で増えていく。これは日跨ぎしても変わらず、ゲームオーバーになったりリセットするまで増え続ける
