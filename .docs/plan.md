# 2 ノルマシステム
次は、ノルマ（家賃）の概念を実装したい
* ノルマは時間と連動していて、1日が終わった時に、所持金から家賃を支払う
* 家賃を払えなければゲームオーバー。最初からになる
 * 営業終了ダイアログ内にゲームオーバーと出す
* 家賃は日毎に、指数関数的に増加する
 * 毎日1.5乗で増えればOK

# 3 キッチンにも店員システムを導入
* キッチンで食事が作られるが、ここにもレジと同様に店員スロットを作成する。
* ひとまず１人適当な初期の店員を置いておく。
 * 注文が入った場合、並列ではなく、店員1人につき1つずつ料理を作ることにする
 * 料理を作っている間、頭の上に料理アイコンを出して、その周りに円形ゲージで進捗を表示
 * 完成したら料理を今のように配置して、ウェイターが配膳できるようになっている

 # お客さんが自動で来店する仕組み
 * お客さんは一定時間のスポーン感覚で生成される。
  * スポーン間隔で生まれて、もし満席の場合は店の外に並ぶ。
* 営業終了時、並んでいたお客さんや店の中のお客さんはすぐ消える。
